# 拾光匣第一次使用

把家庭照片收好，让成长有迹可循。

## 下载安装

从 [GitHub 最新正式发行页](https://github.com/YouHanHan/momentnest/releases/latest) 获取附件。首次使用选择下面的正式程序，不需要安装 Node.js、Flutter 或 Android SDK。

| 设备 | 下载文件 | 使用方式 |
|---|---|---|
| Windows 64 位电脑 | MomentNest-0.4.41-win32-x64-Setup.exe | 关闭旧版拾光匣，运行安装程序，按提示完成安装 |
| Android 8.0 及以上的 arm64 手机 | MomentNest-0.4.30-build41-arm64-release.apk | 把 APK 保存到手机，按系统提示完成安装 |

GitHub 页面自动附带的 Source code (zip/tar.gz) 是开发源码，不是安装包。SHA256SUMS.txt 用于核对下载文件的完整性；媒体工具对应源码 ZIP 供开发者及发行资料核对使用，日常运行不必另行安装。

## 三步开始备份

1. **电脑选图库**：打开 Windows 拾光匣，登记已有照片目录，选择接收手机原文件的照片库。首次使用可以选择一个独立的空文件夹作为接收位置。
2. **手机授权并配对**：打开 Android 拾光匣，授权希望访问的照片和视频。两端连接到同一普通局域网，在电脑的手机连接界面显示配对二维码，手机扫码或粘贴配对信息。
3. **选照片上传**：在手机选择照片或按月份选择媒体，检查目标照片库与日期归档规则，再开始上传。电脑确认保存成功后，手机才标记完成；支持暂停与续传。

接收时电脑应用需要保持运行。当前仅支持 Android → Windows，不能从电脑反向下载原文件，也不提供公网中转。VPN、跨子网及访客 Wi-Fi 隔离可能导致连接失败。

## 建立宝宝成长相册

在「宝宝相册」中建立昵称、生日和头像，主动选择清晰的参考人脸，再使用本地辅助查找。检查「疑似」「待核对」结果，人工确认归属；识别不保证每张都正确。

手机与电脑的宝宝档案、人脸参考、人工归属目前分别保存在各自设备，尚不跨设备同步。原文件上传不等于同步宝宝档案。

## 保存成长水印照片

进入成长照片的水印功能，选择成长年龄、拍摄日期等文字及位置，导出新的 JPEG 副本。原照片继续保留。当前不导出视频成长水印；普通原图预览沿用本机水印显示开关。

## 升级与已有数据

- Windows 正常覆盖升级沿用当前 Windows 用户目录下的 .momentnest 数据，照片库和导出目录独立于程序安装目录。
- Android 覆盖升级必须保持相同应用身份和签名渠道。正式版继续安装正式 APK；此前的调试版不能直接覆盖为正式版。
- 不要为解决签名冲突而卸载旧 Android 应用，也不要清除应用数据；这会清掉宝宝档案、人脸参考、配对、任务和设置。系统相册里的原照片和视频仍然保留，但应用内整理记录不会自动恢复。
- 本版没有完整的应用内状态备份与恢复入口。原照片、归档与水印文件均保留，应用不提供照片或视频删除功能。

## 使用边界

当前发行面向 Windows x64 和 Android arm64，没有经过验收的 iOS、macOS 或 Linux 安装包。特殊 HEIC、视频编码的预览依赖平台解码能力，读取失败会提示，不用低清图片冒充原图。单个传输文件上限为 2 GiB。后台运行受手机系统配额和省电策略影响，不承诺一直运行。

本次公开资料使用独立演示图库与虚构档案。实际界面演示不代表物理手机、大图库性能或所有厂商后台策略已经验收。
