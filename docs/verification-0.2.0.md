## 实际运行

Windows 0.2.0 打包程序使用隔离配置启动：只发布物理网卡局域网地址，拒绝生产入口回环连接，物理私有地址 HTTPS 上传合成内容后磁盘哈希一致；Electron 渲染器公网请求被拦截。

Android API 36.1 只读模拟器安装 0.2.0，以三张自行生成的 JPEG 测试。两张的 EXIF 日期在 2024 年 9 月，另一张在 8 月；第一张原图预先放入测试历史目录并扫描。手机连接显式回环测试服务的模拟器局域网网关，仍使用正式证书固定与 Android 网络绑定逻辑；该测试夹具不改变发布程序的回环拒绝规则。

1. 选择 MonthQA 相册后，9 月自动显示共 2 张、已备份 1、未备份 1、待核对 0，无需选图。
2. 切到 8 月后自动核对，显示共 1 张、未备份 1。
3. 返回 9 月点击只上传本月未备份，确认页仅列 1 张。确认后仅 month-1.jpg 成为上传任务，收到回执。
4. 电脑实际新增 1 个文件，归档到 2024-09-06，SHA-256 与手机测试原图一致。历史已有图片和 8 月图片未上传。
5. 9 月更新为已备份 2、未备份 0，上传按钮不可用。两张分别标记为当前目录与其他目录已有。

6. 最终 APK 覆盖安装后无需重新配对；再次选择测试相册，历史已有和当前目录回执都正确恢复。
7. 最终 APK 关闭模拟器 Wi-Fi 后点击重新核对，界面明确拒绝移动数据及跨网段连接；接收端请求数保持 19、核对数保持 13，没有公网或移动数据回退。

Windows ZIP 内 80 个文件逐个 SHA-256 与最终打包目录一致；交付 APK 与最终构建相同，版本元数据为 0.2.0+3。SHA256-0.2.0.txt 记录安装包校验值。

## 边界与原则

本次没有实体手机和真实双手机并发 UI 联调；多设备规则由真实 HTTPS 协议测试覆盖。没有万张相册性能压力验收、物理断电或全部厂商后台策略验收。扫码使用入口已实现，联调使用手动配对。Windows 文件选择自动化注入测试目录，未手动操作原生选择器。交付仍是调试签名 APK 与未签名便携程序。

月度分组与状态判定独立为小模块，指纹复用沿用既有本地观察记录，不改数据库结构，不引入新依赖。核对、上传共用内容证据与既有协议；备份状态不混用其他目录回执。未加入云端、自动上传或系统防火墙修改；未执行 Git 提交、推送或分支操作。

原 0.1.0 的验收记录保留在 verification.md，不能视为 0.2.0 的所有场景都重复执行。
