# 拾光匣 · MomentNest 产品设计

本项目面向家庭照片、视频和宝宝成长记忆，提供 Windows 本地图库与 Android 原文件备份。当前能力与限制见 [首页](../README.md)，应用标识见 [品牌与身份](branding.md)。

## 首次使用

MomentNest 使用独立应用身份和数据位置，首次启动为空白记录。电脑登记照片库并选择接收位置，手机授权系统相册，双方在同一物理局域网重新配对。既有照片和视频可重新索引，建立宝宝档案后再明确选择参考人脸。

手机与电脑各自保存宝宝档案、参考和人工归属。电脑连接用于手机原文件上传、目标库成功回执查询及补传核对；当前不提供宝宝记录跨设备同步或电脑原文件下载。

## 家庭图库

- 按月份、类型、搜索、收藏和排序浏览照片与视频，分页查询完整授权范围。
- 电脑支持已有目录索引和复制归档；来源与目标的同目录、路径大小写等价及父子包含关系均被拒绝。
- 来源、归档副本、水印副本和失败导出文件均保留，应用没有照片或视频删除入口。
- 日常预览直接读取完整原文件，保持比例、完整画面和原图分辨率，不用缩略图或压缩副本代替。
- 原文件读取失败或目录断开时明确提示，不把无法核实解释为已删除。

## 成长相册

- 在各自设备创建宝宝昵称、生日和头像，并明确选定参考人脸。
- 使用本地模型辅助识别，结果分为已加入、疑似与待核对，人工加入与排除优先。
- 每个宝宝最多保存 20 个参考；参考、头像及相册人工归属分别管理。
- 完成的内容指纹、人脸特征和相同版本分析结果复用；失败重试有明确范围，不自动扩成整库重新处理。
- 普通照片预览沿用全局水印显示开关，主动进入选脸后才显示人脸操作。
- 成长水印导出新 JPEG；当前不导出视频成长水印。

## 传输与保存核对

- Android 到 Windows 使用局域网 HTTPS 直连，验证配对凭据、证书指纹、物理网络和同一 IPv4 子网。
- 使用完整 SHA-256 与大小核对原文件，分块支持暂停、重试和断点续传。
- 批次接收库、日期与归档路径冻结；切库不更改已开始的任务。
- 字节发送完成后等待接收端成功保存回执，才标记上传成功。
- 当前目标库有效回执、其他历史目录已有原文件、未传入与需补传分开表示。
- 临时分块只放在应用专用目录，重试与清理不得触碰已保存媒体。
- 接收成功后可独立进入电脑本地索引与识别队列，识别失败不撤销成功保存回执。

## 安全与运行边界

桌面保持 contextIsolation: true、sandbox: true、nodeIntegration: false；界面经有限 IPC 请求授权的系统操作，验证调用来源与参数。扫描、哈希和模型处理使用既有工作线程，不阻塞界面。

手机后台保存进度并暂停，当前不承诺锁屏持续传输或整理。识别不是身份概率证明，特殊图像和视频编码的预览依赖平台解码能力。首期构建 Android 与 Windows x64，不宣称未经验证的平台可用。

个人媒体、数据库、令牌、配对密钥、签名材料和机器配置不进入源码。应用记录清理与媒体删除分开；原媒体继续保留。源码、实际构建和真机验证分别记录，第三方许可资料见 [许可说明](../THIRD_PARTY_NOTICES.md)。
