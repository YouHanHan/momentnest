# 拾光匣隐私与数据说明

本文描述当前应用的数据处理方式。首次安装源码依赖、下载模型及访问 GitHub 需要互联网；日常相册、人脸辅助整理和水印处理在本机完成，手机与电脑传输使用局域网直连。

## 处理的数据

- 已授权照片与视频的原文件、文件名、完整 SHA-256、大小、拍摄日期及保存位置。
- 本机宝宝昵称、生日、头像、人工相册归属、收藏与水印偏好。
- 本机检测的人脸位置、特征与参考关系，用于辅助整理和查找；不会将相似结果直接视为同一原图。
- 已配对设备、接收端地址、证书指纹、传输任务、分块进度及成功保存回执。

手机和电脑各自保存宝宝档案及人脸参考。当前手机不与电脑同步宝宝相册，不下载电脑原文件；电脑连接用于上传原文件与核对备份。原文件传输保留原始字节，因此原文件已有的定位等元数据也可能随文件保留。

## 保存位置

| 数据 | 位置 |
|---|---|
| Windows 相册索引、回执、证书及生成缓存 | 当前用户目录的 `.momentnest`，核心数据库为 `receiver/receiver.sqlite` |
| Windows 原媒体及归档副本 | 用户明确登记或选择的照片目录 |
| Android 记录与任务 | 独立应用私有目录中的 `momentnest.sqlite` |
| Android 配对令牌 | 系统安全存储；电脑保存对应令牌哈希 |
| Android 新水印副本 | 系统相册 `Pictures/MomentNest`；已有媒体保留 |
| Windows 水印副本 | 用户选择的导出目录 |

电脑便携程序的解压目录不等于数据目录。更换 EXE 名称或升级不会自动清空 `.momentnest`。Android 禁用系统应用自动备份；卸载或清除应用数据可能丢失本机档案、参考、任务与设置，但不能据此认为系统相册里的原照片已删除。

## Android 权限

| 权限 | 用途 |
|---|---|
| 照片和视频读取、部分媒体授权 | 浏览与处理用户允许访问的媒体 |
| 相机 | 扫描电脑配对二维码；也可粘贴配对信息 |
| 媒体位置访问 | 在系统允许时读取原媒体及其元数据 |
| INTERNET | 建立局域网 HTTPS 连接，Android 的局域网套接字同样需要该权限 |
| 网络状态与网络绑定 | 检查并绑定符合要求的 Wi-Fi 或以太网，不修改系统网络开关 |
| 前台服务及同步、媒体处理类型 | 继续执行用户在应用内开始的同步、核对和人脸整理 |
| 通知 | 显示任务计数和阶段，并提供暂停入口；通知不包含照片文件名、人脸特征或配对凭据 |
| CPU 唤醒与 Wi-Fi 锁 | 仅任务运行期间减少锁屏后的执行、传输中断，结束后释放；不修改系统电池或 Wi-Fi 开关 |

授权范围收窄后，只处理当前仍被允许读取的媒体。读取失败会明确提示，不用缩略图代替原图成功预览。

## 网络边界

本版没有照片云端中转、云账号或内置自动更新服务。配对信息包含一次性秘密和证书指纹；连接校验证书指纹，手机凭据放安全存储，不使用全局忽略 TLS 校验的方式连接。

两端使用同一 IPv4 子网的物理 Wi-Fi 或以太网；公网地址、VPN、跨网段及自动外网回退被拒绝。具体策略及限制见 [局域网规则](lan-only.md)。

应用不能控制其他软件。将照片保存到 OneDrive 等同步目录时，该软件可能同步照片；希望完全保存在本地时，应选普通本地目录。应用也不能检测用户另行配置、伪装成本地设备的透明中继。

## 原文件与记录

应用没有删除照片或视频的入口。来源原文件、归档副本、水印副本及失败导出文件均保留；移出相册、取消收藏和移除参考只调整记录。取消未完成上传可清理应用专用临时分块，不清理已保存媒体。

当前没有完整的应用内状态备份和还原入口。不要随意清理电脑数据库、证书或手机应用数据；发布密钥另行保管，不进入源码或安装包。

## 问题反馈

提交问题时只提供必要的脱敏信息：平台、应用版本、操作步骤、错误阶段及可公开的日志。隐藏姓名、生日、个人文件路径、设备地址和配对凭据。不要上传私人照片、人脸特征、完整数据库、二维码、令牌或签名密钥。敏感问题的报告方式见 [安全说明](../SECURITY.md)。
