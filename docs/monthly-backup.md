# 月度备份 · 0.2.0

本文保留 0.2.0 历史规则。手机 0.2.1 已改为系统媒体库直接按月查询、每批最多 100 张，不再提供整个相册扫描；当前规则请阅读 [按月份扫描](month-scan.md)。电脑仍按 YYYY-MM-DD 归档。

## 使用方式

1. 电脑添加接收目录；将以前手工保存照片的多个文件夹加入历史目录，完成扫描。
2. 手机连接同网段电脑，授权相册，选择要查看的月份。
3. 自动核对当前月。三个数量分别是已备份、未备份、待核对，不需要先选择图片。
4. 点“只上传本月未备份”，核对后确认保存目录和日期，再开始上传。

## 状态依据

- 已备份：当前接收目录有经核实的回执，或者其他启用接收目录 / 已扫描历史目录有相同原图。长按查看位置。
- 未备份：已完成核对的登记范围中没有发现相同 SHA-256 与大小的原图。
- 待核对：未处理、照片不可读、历史扫描未完成或目录不可用等。不会加入仅上传未备份的队列。

没有登记或重新扫描的文件夹不在完整性承诺范围内。电脑以往手工拷贝的图片必须先作为历史目录扫描。相似图、压缩图、修改后原图属于不同内容。

## 日期、性能与中断

- 按 Android 相册提供的本地日期分月，日期未知单列。上传归档沿用拍摄日期 / 上传日期 / 指定日期设置，不随浏览月份改变。
- 目录按 250 张一页读取全部已授权照片的媒体属性，缩略图只读取可见部分；目录读取中会提示数量尚未完整。部分授权仅覆盖被授权图片。
- 默认只自动核对浏览月份，可手动核对整个相册。首次流式计算原图 SHA-256，在后台 isolate 执行；核对按照片顺序处理，不同时读取大量原图。
- 后续复用同媒体版本、路径、文件大小与修改时间一致的指纹缓存；电脑文件仍重新验证。上传前重新计算手机原图指纹，不依赖缓存执行跳过或保存。
- 切换月份/电脑/目录会取消旧请求，旧响应不能覆盖新页面状态。可暂停核对；切到后台暂停，回到前台重新读取媒体目录并继续未暂停的核对。
- 自动核对不自动上传。只有用户确认后生成上传任务，传输优先于自动核对。仅上传未备份在确认前、排队时和真正发送前复查，尽量避免其他手机刚完成的重复备份。
- 没有持续监听电脑文件系统或自动重扫所有历史目录。发现电脑文件变化、另一个手机上传后，可点重新核对本月，或重新连接刷新。
- 离线时显示最近核对记录。连接失败不把未核对项标记成未备份。万张相册的真机耗时尚未测量，不能承诺首次核对立即完成。

## 局域网规则

所有核对与上传沿用 [仅局域网规则](lan-only.md)：同子网物理 Wi-Fi/有线 IPv4，禁止公网地址、域名、VPN、移动数据回退和 HTTP 重定向。手机与电脑都应升级到 0.2.0。
