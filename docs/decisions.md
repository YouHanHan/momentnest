# 当前技术与产品决策

- 手机端使用 Flutter + Dart，目录 apps/mobile；桌面使用 Electron + Vue 3 + TypeScript，目录 apps/desktop。
- 产品使用 MomentNest 独立安装身份、数据目录、通道和签名；后续版本固定复用，不读取其他应用的旧记录。
- Windows 交付完整便携目录；Android 分别提供调试和正式签名 APK，升级使用同一渠道。
- 相册、宝宝档案、人脸辅助整理和水印在本机处理，不加入云账号、公网中转或跨设备宝宝记录同步。
- 主进程处理授权的系统访问，预加载层只开放有限 IPC；保持界面隔离、沙箱和来源校验。
- 原文件按完整 SHA-256 与大小去重，接收端成功保存回执决定上传完成；历史目录匹配与目标库回执分开。
- 来源与归档目标不得相同或互相包含。任务归档路径按批次冻结，暂停、重试与续传沿用同一路径。
- 日常预览读取完整原文件；水印显示沿用全局设置，主动选脸才显示人脸选项。
- 相似人脸仅用于辅助整理，人工决定优先。移出相册、取消收藏和移除参考只修改记录。
- 照片、视频、归档副本、水印副本与失败导出文件保留，应用不提供媒体删除能力。
- 所有交付通过统一打包入口递增版本，按实际产物核验版本、架构和签名；源码和二进制分发分别管理。
