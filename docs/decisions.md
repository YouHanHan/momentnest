# 技术决策

## 已采用

- 手机 Flutter + Dart，首期 Android；相册 photo_manager、扫码 mobile_scanner、SQLite sqflite、安全令牌 flutter_secure_storage、前台唤醒 wakelock_plus。
- 桌面 Electron + Vue 3 + TypeScript，HTTPS 和文件接收使用 Node 内置模块，数据库使用内置 SQLite；证书生成 selfsigned，二维码 qrcode。
- 桌面业务放工作线程；界面只使用受限 IPC。手机原图哈希放 isolate，Android 平台通道提供拍摄日期。
- 内容去重按完整 SHA-256 与大小；当前库保存回执和其他历史目录匹配分开记录。
- 默认拍摄日，缺失时使用手机提供的系统创建日期，仍缺失时回退电脑确认的批次上传日；可选上传日和指定日期。批次日期创建后不改变，归档回退日期不自动成为准确月龄依据。
- 首版前台顺序上传，4 MiB 分块，后台自动暂停。优先做到回执可信、状态可恢复，不加入未经验证的后台常驻服务。
- Windows 以免安装便携目录交付，Android 可构建调试与正式签名 APK，各自沿用原签名；不提前加入账户、云端、微服务和自动更新。
- 产品改名为「拾光匣 · MomentNest」，两端显示与交付文件使用新名称，安装身份、数据目录和既有协议保持兼容。

Electron 自带运行时，包体积相应较大；桌面运行不需要用户安装 Node。Flutter 仍遵守 Android 相册权限和生命周期限制，不能绕过系统后台规则。

## 安全与保存边界

二维码携带一次性配对秘密、地址和证书指纹。连接只接受匹配的证书，不全局忽略 TLS 错误；手机令牌存入安全存储，电脑保存令牌哈希。支持撤销设备授权。

请求、分块和文件大小均有限制；网络请求只能引用电脑登记的目录 ID。路径校验拒绝越界、符号链接和目录联接。历史扫描只读，成功回执必须在内容校验与持久保存后产生。

不自动删除手机原图，也不重排历史文件。同一目标库已有相同内容时复用回执，日期设置不移动既有图。

## 尚未纳入首版

Android 持续后台传输服务、mDNS 自动发现、云同步、宝宝相册跨设备同步、视频成长水印、iOS/macOS/Linux 正式分发、Windows 安装向导与代码签名、自动升级。

照片和视频均支持完整原文件传输；Android 正式发布签名从本机忽略目录读取，密钥由维护者单独保管。正式包与旧调试版签名不同，不能直接覆盖旧调试安装。当前不重新生成或更换已有签名配置。

旧 apps/android Compose 骨架保留参考，后续手机开发入口是 apps/mobile。
