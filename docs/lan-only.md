# 仅局域网传输规则（0.1.1）

本版将局域网作为强制约束。照片、文件指纹、配对凭据和任务信息只通过本软件的本地直连接口交换，没有公网服务、云端中转或自动外网回退。

## 允许的连接

- 手机与电脑位于同一个 IPv4 子网；手机连接 Wi-Fi 或有线网络，电脑使用物理 Wi-Fi 或以太网网卡。
- 地址必须是明确的 IPv4 数字地址，使用 10/8、172.16/12、192.168/16 私有地址，或 169.254.1.0 至 169.254.254.255 链路本地地址。
- 局域网本身不需要接入互联网。电脑有线、手机 Wi-Fi 只要位于同网段即可。
- 两台手机可以分别配对同一电脑，各自满足上述条件后上传。

## 强制限制

1. 手机拒绝公网 IP、域名、IPv6、地址简写和非 HTTPS 地址。扫码、粘贴、手动改地址及读取旧配对记录都必须通过校验。
2. Android 每个请求建立前检查物理网络和直连路由，拒绝移动数据、VPN 及经网关到达的其他网段；进程绑定到符合条件的 Wi-Fi/以太网。连接断开时套接字失效，不自动回退其他网络。
3. 手机显式使用 DIRECT，不使用 HTTP 代理；禁止 HTTP 跳转，继续保持证书指纹固定。
4. 桌面只发布物理网卡的私有地址。每条入站连接、每个请求和接收中的分块都校验真实 socket 来源与接收网卡地址，不信任 X-Forwarded-For 等转发头。
5. 桌面拒绝公网、不同子网、VPN/虚拟网卡及生产模式回环入口。Windows 物理网卡识别失败时停止网络接收；不会放宽为全部网卡。
6. 发布版桌面页面阻止所有 HTTP/HTTPS/WebSocket 请求，资源由包内本地协议加载。开发模式只允许固定的本机 127.0.0.1:5173 调试服务器。

这是网络使用策略，不是对网络设备的控制。软件不能识别由用户另行配置、且伪装成本地设备的透明转发/中继；请勿为本软件配置路由器端口映射、内网穿透或转发代理。它也不会控制其他同步软件：如果保存目录属于 OneDrive 等云同步范围，其他软件仍可能同步文件，应选择普通本地目录。

## 使用影响

跨 VLAN/不同子网、IPv6-only、手机 VPN、仅移动数据环境会被拒绝。手机开热点作为路由器的使用方式暂未专项适配，建议两端连接同一普通路由器。

Android 的 INTERNET 权限仍必须保留，因为系统访问局域网套接字也需要该权限；是否允许目标由上述规则限制。CHANGE_NETWORK_STATE 用于将本应用绑定到已连接的局域网，不会修改手机 Wi-Fi 或移动数据开关。

只绑定 127.0.0.1 的 Node/Dart 协议测试保留本机入口；发布程序默认局域网接收模式不开放该入口。Android 发送端不允许连接回环地址。

构建工具下载依赖不属于软件运行时照片传输。此次构建复用已有缓存，没有添加联网 SDK 或更新服务。
