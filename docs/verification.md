- Electron 文件夹选择接口在自动化中注入隔离测试目录，后续的 IPC、目录登记、扫描、数据库和上传均走真实代码；Windows 文件夹对话框未人工操作验收。
- 故障恢复通过真实协议与磁盘状态模拟验证；未模拟操作系统断电、物理磁盘损坏和所有文件系统。
- 当前只支持前台传输；后台自动暂停。没有后台常驻上传、自动发现、自动同步或自动更新。
- APK 为调试签名，Windows 便携包没有配置代码签名；未做应用商店或企业分发验收。
- 大型相册、十万级历史图片和长时间吞吐压力尚未专项测试。

## 工程原则

界面、协议、持久化和文件接收按职责分离；同一接收服务供桌面运行和协议测试复用，减少重复逻辑。首版只引入相册、扫码、SQLite、安全凭据与证书等当前功能所需依赖。没有加入云端服务或额外状态框架。

开发未执行 Git 初始化、提交、推送或分支操作；未修改系统环境变量、防火墙或全局工具版本，未删除用户原图或历史目录。
